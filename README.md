# Кроха — маркетплейс детских вещей с аукционами

**Кроха** — специализированный C2C-маркетплейс для детских вещей: родители покупают и продают коляски, комбинезоны, игрушки, мебель, школьное second-hand — по **фиксированной цене** или через **аукцион**. Это портфолио-прототип: полноценное приложение на PHP с реальными сценариями, тестами и адаптивным дизайном.

---

## Проблема, которую решает проект

Детские вещи почти не успевают износиться, но продать их на общих площадках (Avito, «Юла») сложно:
- каталог замусорен и нет нишевых фильтров (возраст, размер, сезон);
- продвижение платное и непрозрачное, объявления «висят месяцами»;
- покупатели боятся переплатить за хлам и обмана, продавцы тратят время на «поднятие» лотов;
- у неликвидных вещей («пакетов», сезонных, «вырос из») **нет честной цены** — рынок её не определяет.

«Кроха» решает это двумя взаимодополняющими механизмами продажи:
- **Объявление (фикс-цена)** — быстрая продажа «как новое» по понятной цене;
- **Аукцион** — для слаболиквидных лотов цену определяет сам рынок, а не догадки продавца.

## Пользователь

Прототип ориентирован на сегменты, выделенные по исследованиям ЦА (см. `audience-analysis-2026-08-13.md`):

- **Экономные покупатели** (≈35–45%): ищут «как новое» за 30–50% цены нового.
- **Продавцы-мамы** (30–40% мам с детьми 0–7 лет): хотят вернуть деньги, освободить место, продать «пакетом».
- **Рациональные/осознанные**: брендовое (REIMA, Cybex) по цене б/у — ядро аукционной аудитории.

## Основная функция

Полный цикл сделки «разместил → нашёл → связался → договорился»:

1. **Продавец** размещает объявление за пару минут или создаёт аукцион для неликвидного лота.
2. **Покупатель** находит вещь через поиск и детские фильтры (категория, возраст, размер, сезон, город, цена, «только б/у»).
3. Для аукциона — участие в торгах: ручные ставки, **автоставки (proxy bidding)** до своего лимита, **антиснайпинг** (продление на 3 минуты при ставке в финале).
4. Стороны общаются во встроенных **сообщениях** и договариваются о сделке (самовывоз — стандарт ЦА).

## Формат результата

- **Объявление:** опубликованная карточка в каталоге — фото, цена, состояние, возраст, размер, сезон, город, профиль продавца с рейтингом.
- **Аукцион:** по истечении срока фиксируется **победитель** (максимальная ставка) и контакт с продавцом; при недоборе резервной цены — статус «Не продан».
- **Сделка по объявлению:** продавец отмечает «Продано» и выбирает покупателя.
- **После сделки:** обмен подтверждением получения и **отзывы** (рейтинг 1–5 звёзд) с обеих сторон.
- По всем событиям — **уведомления** (перебили ставку, победил, купили, ответ на жалобу и т.п.).
- **Модерация:** жалобы на объявления и лоты обрабатывает админ-панель; автору жалобы приходит ответ.

## Минимальный функционал (реализовано)

**Объявления:**
- размещение с фото, категорией, возрастом, размером, сезоном и состоянием;
- «Отдам даром» (цена 0 ₽) — убирает трение раздачи;
- управление объявлениями в личном кабинете (опубликовать / продано / снять / удалить);
- избранное ♥.

**Аукционы:**
- создание лота: стартовая цена, срок (1/3/7 дней), опц. «Купить сейчас» (BIN);
- ручные ставки с автошагом, автоставки до лимита, антиснайпинг-продление;
- живой таймер, публичная история ставок, итог «победитель» / «не продан».

**Каталог и поиск:**
- debounce-поиск, фильтры (категория, возраст, размер, сезон, город, цена, «только б/у»), сортировка;
- переключатель «Объявления / Аукционы / Всё».

**Сообщество и доверие:**
- регистрация, вход, восстановление пароля; профили с рейтингом и отзывами;
- встроенные сообщения между продавцом и покупателем без ухода с площадки;
- история просмотров, панель администратора, модерация отзывов и жалоб.

**Безопасность:** CSRF-токены, подготовленные запросы (PDO), экранирование вывода, защита приватных данных пользователей.

**Тесты:** автономный набор 97 проверок (в память, SQLite) — `tests/run_tests.php`.

## Технологии

| Слой | Технология |
|---|---|
| Бэкенд | PHP 8+ (строгая типизация), PDO |
| Фронтенд | HTML5, CSS3 (собственная дизайн-система), ванильный JavaScript (модальные окна на `<dialog>`, debounce-поиск, предпросмотр фото) |
| База данных | SQLite — локальная разработка; MySQL (utf8mb4) — хостинг; единый PDO-слой и совместимые схемы в `database/` |
| Тесты | Самописный PHP-раннер (`tests/run_tests.php`) |
| Шрифты | Baloo 2 (оформление), Nunito (текст), JetBrains Mono (цифры/таймеры) |

## Установка и запуск

Требование: **PHP 8+** (CLI, с модулем PDO SQLite).

```bash
# 1. Применить схему БД (создаёт database/kroha.db)
php setup.php

# 2. Загрузить демо-данные
php seed.php

# 3. Запустить локальный сервер
php -S 127.0.0.1:8091

# Открыть http://127.0.0.1:8091
```

**Демо-аккаунты из `seed.php`:**
- продавцы/покупатели: `masha@kroha.test`, `sveta@kroha.test`, `anna@kroha.test` — пароль `demo`;
- администратор: `admin@kroha.test` — пароль `admin123`.

> `config.php` переключает драйвер БД (`DB_DRIVER = 'sqlite'` / `'mysql'`) — схема для MySQL в `database/schema.mysql.sql`.

### Тесты

```bash
php tests/run_tests.php
```
